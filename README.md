# alocacao-espacos-tenda-evento
## Descrição do Problema
Um organizador de eventos precisa distribuir expositores em uma tenda grande. Cada expositor tem uma área solicitada e o valor do stand. O sistema deve informar quais expositores cabem na tenda seguindo a ordem de pagamento (maior valor primeiro) até atingir o limite de metros quadrados.
## Requisitos
* Receber uma lista de dicionários com nome, area e valor.
* Ordenar os expositores pelo valor do stand em ordem decrescente.
* Somar as áreas até atingir o limite de 100m2.
* Exibir a lista final dos expositores aceitos e a área total utilizada.
## Exemplo de Uso
Entrada: lista de 4 expositores com áreas variadas.
Saída: Lista dos aceitos e total de m2 ocupados.
